# Deep Research Protocol

## Process
1. **Decompose** the topic into 3-5 specific sub-questions
2. **Search** each sub-question separately (DuckDuckGo + official docs)
3. **Fetch** top 3-4 sources per sub-question
4. **Extract** key claims with source attribution
5. **Cross-verify** claims across multiple sources
6. **Synthesize** into a structured report with inline citations
7. **Flag** any conflicting information or low-confidence claims

## Output Format
- Executive summary (2-3 sentences)
- Key findings (numbered, with citations)
- Comparison table (if applicable)
- Confidence assessment per finding
- Source quality ranking
- Recommendations

## Source Quality Tiers
1. Official documentation, .edu, .gov
2. GitHub repos with >100 stars, technical blogs
3. StackOverflow, dev.to, Medium
4. Forums, Reddit, unknown blogs
